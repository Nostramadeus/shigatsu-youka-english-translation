# STYLE.md (v2) — fixed conventions (Opus 5.5 remake, 2026-09-26)

Replaces notes/STYLE.md for all v2 work. Source tags: [O-nn] owner ruling (binding), [F] orchestrator ruling
(reversible; Q-id where one exists), [M] model-made rule kept after re-check. JP examples from read/chunk01.txt.
Doctrine: notes/v2/METHOD.md. Devices (blank cells, dashes as channels, split words, masks): notes/v2/CORE-RULES.md.
This file cites no "convention" for JP punctuation; any future claim of one must cite a MODERN source (the 2022
文化審議会建議「公用文作成の考え方」, not the 1946 rules) [O-24].

## Names and address
- **Name order: given name first** (Haruka Niimura). Historical の-names (Minato no Tsunamune) and titles stay as
  they are; surname-only address (五島 -> Goto) is unaffected [O-09].
- **Romanization** [F]: modified Hepburn, NO macrons (the font cannot print them), long vowels dropped (Goto, Kotaro,
  Ryoji); ん before a vowel = n' (Shin'ichi); づ = zu, ぢ = ji.
- **Honorifics stay as suffixes on names** [O-05]: -san, -kun, -chan, -senpai, -sensei, -sama, -dono, -nee, -nii
  (チガ姉 -> Chiga-nee). A dropped or changed suffix is an event: flag it.
  - JP: 「いつもいつも、春花ちゃんには悪いわねえ」 EN: "We're always imposing on Haruka-chan."
- **Suffix scope** [M]: kept when what precedes is a personal name, a nickname used as a name, or a title used as a
  name (先輩, 先生, 部長). On a COMMON NOUN the suffix is zero and the politeness goes into the noun: お客さん = "the
  customer", 皆さん = "everyone", 神様 = "God", お巡りさん = "the officer". Standalone 先生: address = "Sensei",
  reference = the profession word. Names inside documents keep their suffix like speech; no invented Mr./Ms.
  [F, Q1485].
- **Kinship words, speaker's own relative** [F, Q1561; review ruling on kinship register]: お母さん / 母さん = Mom,
  お父さん = Dad, in first-, second- and third-person possessives ("my mom", "Natsumi's dad"); 父 / 母 = "my father" /
  "my mother" register; a title possessive ("Senpai's mother") takes father / mother. The same word is used in
  narration. おばさん (aunt) = Aunt, おじさん = Uncle, お婆さん = Grandma, お姉ちゃん = Sis (provisional).
  お姉さん and お姉ちゃん are two words and never merge.
  - JP: 「お父さんまだ？」 EN: "Dad's not back yet?"
- **Kinship words, non-relatives** [M]: what a native English speaker says there: おじさん to a shopkeeper = "sir" /
  "Excuse me", お姉さん to a stranger = "miss", おばあさん (stranger) = "ma'am" / "the old lady". Spouses using
  お父さん / お母さん to each other = "Dad" / "Mom" as said; if the English would misread as the speaker's own parent,
  file a QUERY [M, changed: the old "else use the name" supplied a word the JP does not say].

## Speech level and voice
- Carried by English diction per the CAST / RELATIONS row, never by invented quirks [O-05].
- **Default mapping for a speaker with no CAST card** [M]: 乱暴 = heavy contractions, blunt words, imperatives;
  タメ口 = normal contractions; 丁寧 (です・ます) = normal contractions PLUS polite words (please, would you); 敬語
  proper (尊敬語 / 謙譲語) = few contractions, formal words ("allow me"); fixed keigo formulae = the GLOSSARY rendering.
  A CAST card's explicit rate wins.
  - JP: 恐れ入りますが、1度この世界を閉じますので、再度起動していただけますでしょうか。 (謙譲語) EN: "I beg your
    pardon, but I will close this world once; would you be so kind as to start it again?"
  - JP: 「おはよう……」 (タメ口) EN: "Morning..."
- A drop from an unbroken polite level to plain form is an event: the English drops too, for that cell only
  [F, Q1722].
- **Dialect** [F]: never an English regional or class dialect, never eye-dialect, never "Engrish". Carry it by
  rhythm, word choice, contraction rate and the tags pre-listed for that speaker in CAST, plus ONE TN at the
  speaker's first dialect line per file naming the dialect. A dialect the narration names but does not write stays
  unwritten. ～アル = plain English + TN; ～ざます／～ですわ = over-formal English, no contractions.
  - Test [M]: could a reader place the word or spelling on a map or in a class? Then it is banned ("Oi", "Yo",
    "eh", "y'all", "innit", "aye", "lass", "my dear"). Allowed contractions: gonna, wanna, gotta, c'mon, dunno,
    'cause. Banned spellings: ya, yer, nothin' (any dropped -g), wot.
- **Particle, modal and benefactive tails** [M]: ね, よ, さ, な, なあ, かな, だろう, のだろうか, のだ, っけ are carried by
  English mood, word order and punctuation, not by a tacked-on ", I wonder" / ", you know" / ", I'm sure", unless
  the speaker's CAST card fixes that tag. てくれる / てもらう / てあげる are zero unless the favor is the point.
  Test: cover the tail; if the sentence says the same thing with the same force, it was a particle.
  - JP: いつの間に眠ってしまったのだろう。 EN: "When had I fallen asleep?"
  - JP: 春花は1か月前からいつもそう言ってくれる。 EN: "Haruka has said that every time, for a month now."
- **Set phrases** [M, changed]: a verb or noun inside a set phrase takes the set-phrase MEANING (弁を吐く = deliver
  words, not spit; 口にする = say). Rendering a set phrase by its literal parts is not an error where the meaning
  survives and the English reads (O-04); it is an error only where the literal words add or lose meaning. A
  reviewer does not replace a readable literal image; a hard-to-read one goes to STIFF-CANDIDATE.
  - JP: 私の力の及ばないところで事件は動いていたのだ。 EN: "The incident had been moving somewhere beyond my
    power." (meaning kept; "beyond the reach of my strength" is a STIFF-CANDIDATE, not an edit)
- **AI-isms banned** [O-07]: "Well," / "I mean," / "Look," / "honestly" / "kind of" / wry asides / "It's not X,
  it's Y" where the JP has one clause. The ban is for English with NO JP counterpart; a GLOSSARY row prescribing
  "Well" for まあ is not an AI-ism [M].

## English variety
- AMERICAN spelling and vocabulary project-wide: elevator, apartment, first floor = 1階, trash, intercom, center,
  color, -ize. No British forms [O-08, Q1161].
  - JP: その時、インターホン。 EN: "Just then, the intercom."

## Punctuation
- **Quotes** [F]: 「」 = straight "..."; 『』 = '...'; straight "..." in the SOURCE (text nobody present is speaking:
  phone messages, broadcasts, documents, a mute character's writing) = curly “...”; bare cells stay bare. A 「」
  line with a line break inside keeps the break.
- **Ellipsis** [F]: …… or longer inside a sentence = "..." once; leading ellipsis kept ("...I see"). A cell that
  is ONLY ellipsis = one "..." per JP … (…… = "......") [Q1322]; with a mark after it, the count then the mark.
  An ellipsis-only cell stays distinct from an empty "" cell.
  - JP: 「…………？」 EN: "............?"
- **Dash** [F]: ―― = ― (U+2015), one mark, at the JP position; never the em dash U+2014 (not in CP932). A run of 3+
  ASCII hyphens is a rule line: copy it.
  - JP: ――夢の中に響く、時計の音。 EN: "―Echoing inside a dream, the sound of a clock."
- **No extra stop** [M]: ……。 = "..." and ――。 at cell end = "―".
  - JP: 私は明かりのついてない自室のドアを開け――。 EN: "I opened the door to my unlit room―"
- **Invented dash** [F, Q2120 + Q2281 + part-3 follow-up, merged]: an English ― where the JP has none is allowed
  only (a) across a cell break inside one speech where no punctuation can carry the self-interruption, (b) where a
  comma would make a splice AND the JP is one sentence, (c) where a comma would misread (a fronted name read as an
  address; a pause right after a closing quote ending in ! or ?). Otherwise the JP and EN dash counts match.
- **Punctuation follows English grammar in every printing** [M]: a question gets its question mark even where that
  printing's JP has none; two printings that differ only in optional ？ 、 。 get identical English.
  - JP: 「食べたものはどこへ行ってるんだろ」 and 「食べたものはどこへ行ってるんだろ？」 EN (both): "Where does all
    that food go?"
- ！？ = "!?"; ？！ = "?!"; ！！ = "!!" [F].
- **Commas as felt pauses [O-30] = CHIP-01.** A JP 読点 is a pause the reader feels: keep it as an English comma
  wherever English can hold one, INCLUDING after a sentence-initial conjunction; drop it where English grammar cannot
  take one (between a subject and its verb, before a short object). SOFT: overruled whenever the English would
  sound absurd; never applied mechanically.
  - JP: でも、あの人は死んだ。 EN: "But, that person died."
- **Space at a {PAUSE} cell boundary [O-31]:** when one text box is split into two cells by {PAUSE ""} and the first
  cell ends in sentence punctuation or a closing quote, the English first cell ends with ONE ASCII space (the engine
  joins the cells). Drafters write it; tools/pause_space.py sweeps it.

## Order [O-33] = CHIP-02
Where the JP orders its images to carry sequence or logic, the English keeps that order even at the cost of a
fronted phrase, if the English stays readily comprehensible on first read; otherwise the neutral order wins. Soft,
forward-looking: shipped lines are not re-edited for it.
- JP: ――夢の中に響く、時計の音。 EN: "―Echoing inside a dream, the sound of a clock." (not "The sound of a clock,
  echoing inside a dream.")

## Narrative tense [F, Q1087; M, changed]
JP first-person narration mixes non-past and past cell by cell; English narration has one base tense. Do not follow
the JP tense cell by cell, and do not put a whole block in the historical present.
- The base is PAST for anything perceived or happening at the story moment, sensations included.
  - JP: ソファで座ったまま眠ったせいか、少し身体が痛い。 EN: "Maybe because I had fallen asleep sitting up on the
    sofa, my body ached a little."
- PRESENT is allowed for the narrator's own thought at that moment (a judgment, a resolution, a ～のだ explanation, a
  question to herself); check: put "I thought:" in front, and if it still reads as her words at that moment, the
  present stands. Also for a general fact still true at the time of telling.
  - JP: 分かっている。後悔したってどうにかなるものではない。 EN: "I know. Regretting it won't change anything."
- A block the source sets wholly in the present as a device (a dream, a running commentary) stays present, with a
  DECISION row.
- (The old cap "at most one flip per text box" is dropped as a rule: it had no JP basis. A reviewer still checks that
  every flip reads as intended.)

## Stiffness [O-04]
Calqued subjects and JP order STAY: 目を開けると、時刻は深夜0時を回っていた。 = "When I opened my eyes, the time had
gone past midnight." Only a clearly unreadable line is an error; candidates go to a STIFF-CANDIDATE list for the
owner. Agents add no stiffness rules.

## Numbers and dates
- [M] DIGITS for clock times, dates, ages, sums of money, measurements, room / page numbers, and anything read off a
  display, label or document. WORDS for counts under ten in prose and speech. The JP's Arabic-versus-kanji choice
  is not carried.
  - JP: 「今は、私たち2人しかいないからね……」 EN: "It's just the two of us now..."
  - JP: 0時を回ったということは今日は五月六日。 EN: "Past midnight means today is May 6."
- [F, Q1560/Q1563] A time keeps the source's form (a 24-hour display stays "23:50"). A duration of 2 or more units
  takes digits ("3 days"); ONE unit takes the word ("about an hour later", "a month ago").
  - JP: 1か月前 EN: "a month ago"
- [F] Calendar: dates stay as written; an era year keeps the era name romanized ("Shiyo 805, August 1"); no
  conversion, no TN equating them.

## Sounds [M]
Render a sound by the English sound-word or phrase a reader can hear, in narration and speech alike. Romanize only
a sound the text itself quotes AS a sound (a child's word for a noise, a mimicry), once, with a gloss.
- JP: 「ゲホッゲホッ！　だ……大丈夫……」 EN: "Cough! Cough! I-I'm fine..." (not "Geho! Geho!"; no asterisks)
- Stretched endings [F, Q1484]: a stretch on a content word stretches the English word ("amaaazing"); a stretch on
  a grammatical ending is dropped.

## Translator notes [O-06]
- A `[TN: ...]` is allowed where a point is untranslatable AND the note is not a spoiler: the first time a
  character speaks with 僕 is the owner's own example. Also: the first occurrence of a romanized term; a speaker's
  first dialect line; a pun kept at surface meaning (state the mechanism in one clause, never the punchline); a
  fact every JP reader gets from the word when a character's reasoning turns on it [F, Q1482-Q1486]. Never an
  explanation inside the line itself [M, changed: the old closed five-case list and its ban on register notes are
  replaced by the owner's test].
- Length: 12 words maximum (it prints inside the text box) [M]. Position: end of the line, after the closing quote;
  when the term sits in the first of two cells of one speech, at the end of THAT cell [F, Q1320].
- Once per FILE per term (scenes are played separately), and in every route variant that has the line [F, Q1490,
  Q1126]. One wording per term project-wide, reused byte for byte (花見 = "cherry-blossom viewing") [F, Q2121]. If
  the first line already carries a note, the second goes on the term's next occurrence in the file [F, Q2280].
- Logged as a TN row in the agent's log.

## Box length [O-11]
Never shorten a translation to fit a box; the engine pages long boxes. Do not wrap manually.

## Character set and glyphs
- CP932 only [F, font test 2026-09-25]. Allowed in text the translator writes: ASCII plus “ ” ‘ ’ … ― − ～.
  Not representable: em dash, macrons, accented letters. Quotes are straight ASCII except the curly case above.
- 【 】 and ～ are allowed [O-34]. U+3000 and full-width （） only where a CORE-RULES device needs them; the device
  row wins over the checker, and a HARD line on such a glyph is waived with a DECISION row [O-34, M].
- A layout full-width space is never replaced by ASCII spaces (in the proportional face an ASCII space is about a
  third as wide, so the device vanishes) [M]. The owner distrusts silent flattening of layout spaces: earlier rows
  that swapped U+3000 for ASCII are re-check candidates [O-35].
- A leading U+3000 that indents a continued cell inside one quoted turn is KEPT [F, Q1801].
  - JP: 「よう！／　調子はどうだ？」 EN: "Hey!" / "　How're you doing?"
- ・ (U+30FB) is kept as a bullet where the JP uses it [F].
- Font: message boxes use the proportional ＭＳ Ｐ明朝; no italics, no bold, plain text only [F].

## Ruby [O-32]
- Reading-aid rubies (a hard kanji, a name reading) are dropped automatically in the English build.
- A meaning-carrying ruby (double reading, pun, 圏点 emphasis dots, a foreign word glossed by its reading) is KEPT
  above the English: keep the `<STYLE ID="n" RUBY="jp">` tag on the English words that carry it and add a row
  `jp ruby<TAB>en ruby` (UTF-8, CP932-safe, short). For the 5.5 tree the row goes in
  <repo>/lns-en-55/ruby-<id>.tsv (the old tree used patch/ruby-<id>.tsv). Too long to fit:
  a TN instead. Tag parity: every RUBY attribute stays byte-identical [F, Q1321].
- Ruby-residue spacing in the dump (stray spaces around a word) is stripped; translate the word normally [F].
  - JP: 強烈な吐き気とめまいに 苛 まれる。 EN: "I was tormented by fierce nausea and dizziness."

## Source errors
- Typos (dropped or doubled kana, misconversions): translate the intended text, never reproduce the typo, log a
  QUERY with status=typo [F]. Mojibake cells: translate the decoded Japanese, log as typo [F, Q872]. Deliberate
  broken Japanese that a character or the narrator notices is a device, not a typo (CORE-RULES).

## Engine and tables
- Keyword spans: English words may move across a STYLE span boundary so that only the keyword sits in the colored
  span; the tag sequence stays unchanged [F, Q1562].
- Never translate: 閲覧年月日 (object names), 項目 of システムテキスト, 文字列名 of リンク, the path columns of the 事典
  tables, any DBLocate key column [F].
- Anonymous message-board posts use one register everywhere: all lowercase, mirrored exactly (sentence starts, "i",
  proper nouns) [F, Q2122].
