READ THIS BEFORE PLAYING
========================

UNOFFICIAL FAN TRANSLATION (非公式・二次創作). Not affiliated with, endorsed by, or supported by New++. Please do not contact the author about this patch.

TWO THINGS NOT TO DO
  1. Do not use the game's own screen-switch button (the toolbar's second button) to go full screen.
     It changes the display mode and shrinks every other window until you switch back. Play in the
     normal window, or use a window upscaler (see below).
  2. Do not look the game up online. Store pages, reviews and wikis state its length and structure
     in the first paragraph.

FULL SCREEN WITHOUT THE GAME'S OWN BUTTON (optional)
  The game window is a fixed 960x540. Magpie (free, open source, github.com/Blinue/Magpie, Windows 10
  1903 or newer) captures the window and draws it full screen with a good upscaler. Nothing in the game
  is modified. Download it, unzip it into a folder named "Magpie" next to the game exe, then start the
  game with "Play (fullscreen).cmd" (it starts Magpie in the tray, then the game). With the game window
  in front press Alt+Shift+A to scale. If the scaled screen is black, switch the capture method in
  Magpie's profile settings. Without Magpie the .cmd just starts the game windowed.
