Shigatsu Youka ~April 8th~ (死月妖花～四月八日～) -- unofficial English patch (build date = this zip's file name)
=============================================================================================

UNOFFICIAL FAN TRANSLATION (非公式・二次創作). Not affiliated with, endorsed by, or supported by New++. Please do not contact the author about this patch.

What this is
  A fan translation of the opening stretch of the free visual novel by New++ (v2.0.0.4):
  story text, menus, notices, data tables and pictures for everything you can reach in that
  stretch. Text beyond it is still Japanese for now. When story text turns Japanese, you have
  reached the end of the translated stretch; more will follow.

Install (no game files are modified)
  1. Get the Japanese game v2.0.0.4 from the author (freem, game 19917) and unzip it.
  2. Copy every file and folder from this zip into the game folder, next to
     死月妖花～四月八日～.exe. Keep the folder structure (the データベース folder goes
     next to the exe).
  3. Start the exe as usual. The engine loads the loose files instead of the packed ones.

Updating from an earlier build of this patch
  Copy the new zip's files over the old ones (overwrite when asked). Back up save.dat first, just in case;
  saves made with an earlier build keep working, and the game continues from where you stopped.

Uninstall
  Delete the copied files and folders (.lsb files, データベース, グラフィック). Your save.dat is untouched.

Translation philosophy
  We keep the order of ideas and the feel of the Japanese wherever English allows, and we value that
  over 100% natural-sounding English. If a line reads a little foreign, that is on purpose.

Notes
  - First boot: the game runs an autosave self-test. Follow the English prompt; it may
    close once and ask you to start it again. This is the original game's behaviour.
  - Names are given name first. Honorifics (-san, -kun, -chan ...) are kept.
  - Translator notes appear at the end of a line as [TN: ...].
  - The title logo is artwork and stays Japanese.
  - The two words on the window toolbar are part of the game engine and stay Japanese:
      終了 = Quit        画面切替 = Screen switch (windowed / full screen; see README-BEFORE-PLAYING)
  - Windows Defender sometimes flags the original exe. Nothing in this patch touches the exe.
  - Locale and fonts: the game was tested on a Japanese-locale Windows. If the game does not start,
    shows boxes instead of letters, or the text looks wrong: set Windows' system locale to Japanese
    (Settings > Time & Language > Language & region > Administrative language settings > Change system
    locale), or run the exe through Locale Emulator. Add the Japanese language pack too; it brings the
    story font (MS PMincho). The original Japanese game has the same requirement. The picture text in
    this patch is baked into the pictures and needs no fonts.
