Every translation rule, with who made it (Shigatsu Youka EN, rule books as of the 2026-09-26 remake)

Unofficial fan translation (非公式・二次創作). Not affiliated with New++. Private review page: never publish (shows the Japanese script).

One row per rule. A rule is one instruction a drafter (the agent who writes the English) or a reviewer (the agent who checks it) must obey. Pure tool mechanics (block sizes, file paths, log formats) are left out.

Where each rule comes from:

you (OWNER, O-xx) ──► OWNER-RULINGS.md ──┐ Fable (FABLE, F) ──► FABLE-RULINGS.md, [F] tags ──┼──► the rule books ──► drafters + reviewers pass-1 questions (QUERY, Q####) ─► Fable's answer ──┤ (METHOD, STYLE, an agent model wrote it (MODEL, M) ─────────────────┘ CORE-RULES, CHIPS, BRIEF)
OWNERYou ruled it. Binding. Cited by O-id and date.
FABLEThe orchestrator decided it. You can reverse it.
MODELAn agent model wrote it into a rule book and nobody asked for it. These are the ones to audit. The book it lives in is named.
QUERYA translating agent in the first pass (pass 1) asked a question (a "Q" row); Fable answered it; the answer became a rule.

Status says what the 2026-09-26 remake of the rule books did to the rule: kept, changed, added, or dropped. A red overruled by O-xx tag means a later ruling of yours replaced it, and the books still say the old thing. A green confirmed O-xx tag means you approved it on the questions page.

Examples: Japanese (JP) and English (EN) lines come from scene 1 (file 00000024) or are everyday lines that reveal nothing. Rules with no safe example have none.

Terms used below. Cell: one piece of text the game engine shows at a time. TN: a translator note, written as [TN: ...] inside the line. CAST card: the notes file entry describing one speaker's voice. GLOSSARY: the locked term list. QUERY row: a logged question for Fable. STIFF-CANDIDATE: a list of hard-to-read lines for you to judge.
